## The signal taxonomy

Five families of public proof mark a target. Each is a *pointer to prioritise an invitation*, never a wealth dossier (see [DPDP guardrails](#dpdp--compliance-guardrails)).

| Family | What it proves | Where it shows | Strongest tells |
|---|---|---|---|
| **Money proof** | Scale of capital | X/fintwit, Reddit, press | Broker-linked verified annual P&L (e.g. "Verified Zerodha PnL — ₹25L/365 days"), crore-margin/withdrawal screenshots, charges in lakhs |
| **Frequency proof** | High-frequency / automation | API forums, GitHub, broker communities | Requests for **millisecond order timestamps**, 5,000+ instrument subscriptions, static-IP/TOPS/algo-ID questions, order-lifecycle debugging |
| **Tooling proof** | Sophistication | Quantsapp, Sensibull, Streak, Tradetron, AlgoTest, GitHub | Advanced screenshots, strategy-creator status, live-deployment repos |
| **Community proof** | Engaged seriousness | MadeForTrade, TradingQnA, Upstox Community, quant Telegram/Discord | Repeated technical posts on APIs, options, margin, execution, tax |
| **Referral proof** | Vouched access | CAs, wealth managers, prop alumni, fintwit | F&O tax-audit practices, family-office advisors, ex-iRage/AlphaGrep/Graviton/Quadeye |

## The concierge funnel

The motion is **invite-only**, not scraped cold spam. Public signals only decide *whom to invite*; everything after is consented.

A two-layer score keeps it disciplined: public signal decides the invite (5 = direct scale proof → concierge; 4 = frequency proof → technical interview; 3 = tooling → design partner; 2 = influencer/channel → referral partner; 1 = generic → nurture only). Private qualification after opt-in confirms capital (₹20L+ HNI / ₹1cr+ UHNI concierge), activity, automation, pain, and suitability — with **no growth-hack exceptions**.

## The retail base funnels up (first-party, permissioned)

docs1's serious-trader base is Arrow's *own* highest-quality lead source — surfaced by first-party behaviour, never third-party scraping:

| In-product behaviour | Upgrade trigger | Elite offer |
|---|---|---|
| F&O turnover above threshold | Charges/tax/risk pain | True-cost audit + CA packet |
| Margin/collateral above ₹20L | Pledge/cash optimization | Option-seller concierge |
| API key + order APIs used | Static IP, rate limits, postbacks | Algo Cloud technical beta |
| Heavy basket/iceberg/expiry trades | Legging/slippage risk | Expiry cockpit + execution audit |
| High market-hours support severity | Needs named escalation | Elite support desk |
| Multiple/family/HUF/company accounts | Reporting & permissioning | Family / pro-desk workspace |

Show "you may qualify for Arrow Elite" **only** when thresholds are met, explain why, and ask the user to request a call — never expose hidden wealth scores to sales without consent.

## DPDP & compliance guardrails

Public footprints are not permission to build shadow profiles. Under the **DPDP Act (Rules operational since Nov 2025)** and SEBI/advertising rules:

| Rule | Practical guardrail |
|---|---|
| Data minimization | Store only public URL, handle, signal category, date, reviewer note — never inferred income/net-worth/sensitive attributes |
| Purpose limitation | Use signals only for "invitation to Elite qualification"; no reuse |
| Consent before contact | Beyond a public reply, get platform-permitted basis or explicit opt-in; referrals require the client to opt in first |
| Notice | Opt-in form states the iRage/Arrow entity, purpose, data categories, retention, withdrawal route, grievance contact |
| Retention | Delete unqualified leads in 90–180 days unless they opt in |
| No minors | Never target student communities with leveraged F&O/algo invitations |
| No automated wealth scoring | Human review + private suitability, not algorithmic eligibility decisions |
| SEBI advertising | No return claims, no P&L bait, no signal-selling; finfluencer partnerships need labels, registered-advice boundaries and compliance-reviewed scripts |
